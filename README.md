# 题目池取值分布 Demo

公开演示：https://nolfacalatroni776-design.github.io/appen-question-distribution-demo/

本 Demo 演示采集工作流题目池中的「取值分布」列。页面使用模拟作答和文件元数据，全部统计在浏览器内计算。

## 演示操作

1. 在「题目池」查看各题的选项、数值、时长或文件大小分布。
2. 在 AC203 的字段下拉框切换「是否合成数据」「年龄」「熟悉的语言」。
3. 点击图表展开完整分布，选择选项或区间，再查看对应记录。
4. 切换「提交时间」为近 7 天或近 30 天，观察分布变化。
5. 查看多图片题的「每条记录的图片数」和「单张图片大小」，比较统计单位。
6. 使用「导出分布」下载 CSV，使用「重置演示」恢复初始状态。

## 发布

GitHub Pages 从 main 分支的根目录发布。index.html 已包含全部样式、脚本和模拟数据，没有外部依赖。

页面包含 12 道示例题和 3,450 条模拟已提交记录，未连接生产数据接口。上传文件仅提供模拟元数据。
